# Cover

The design system's cover image, used at the top of `index.html` and the live copy. It is not part of the app.

## Rules
- Built only from the four colours and the tokens: an `accent` slab, two `fill` blocks and one `ink` pill on `surface`, with discs at `size-play`, `size-target` and `size-avatar` on a `size-target` pitch, `space-4` gutters and `radius-md` corners.
- The name in `title` weight beside it, and the line "Four colours, flat shapes, big words."
- Its colours come from `tokens.css`, so it follows any change to them.
