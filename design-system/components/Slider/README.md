# Slider

The seek bar and the volume bar on Now Playing.

## Rules
- Track `size-track` in `fill`; played part and the `size-handle` disc in `accent`. The whole 64dp row is touchable.
- Seek: times under the track in `time`. Back 10 s / Ahead 10 s always accompany it, so dragging is never the only way.
- Volume: the word "Volume" before the bar; it moves the phone's media volume and never changes it on its own.
