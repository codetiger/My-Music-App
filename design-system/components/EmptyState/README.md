# EmptyState

What a list or screen says when there is nothing in it yet.

## Rules
- One `body` sentence, regular weight, where the content would be. No picture, no bold, no colour.
- Say what will appear and, when the user can do something about it, how: "Songs you add will be listed here.", "No songs in this list yet. Open a song and tap Add to List.", "Songs you play will show here.", "Nothing is lined up.", "Nothing is playing.", "Nothing here."
- A button appears only when it undoes what made the list empty: "No songs match “kanna”." with **Clear Search** (`close`).
