# SettingsRow

One item on Settings: its name, its current value in words, and a chevron.

## Rules
- Flat `fill` row, `radius-md`, at least `size-row-tall` (88dp), `space-2` between rows. Name in `body-strong`, value in `body` below. Both wrap.
- Five rows, in order: Your Name and Photo, Text Size, Default Playlist, Storage, Phone Setup.
- Phone Setup value: "All done" with a filled check, or "1 step left" with a clock; the value icon is `size-icon-sm`. Your Name and Photo shows the 48dp drawing first.
