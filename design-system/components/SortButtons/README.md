# SortButtons

Choose one short option that changes what a list shows: **A–Z**, **Newest**, **Most Played** on Songs.

## Rules
- Flat pills (`radius-full`), 64dp tall. Pills mean "choose one"; rounded rectangles mean "do something".
- Unselected: `fill`, `ink`. Selected: `accent` fill, `on-accent` word and a check icon in front (the cue that works without colour).
- A visible "Sort" label sits above. Pills wrap rather than scroll sideways. The choice is remembered.
