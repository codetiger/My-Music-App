# HomeScreen

Home put together: the one screen for lists and songs. Title bar, the one 96dp Play button, "My Lists" tiles, then "Songs" with the search box, sort buttons and every song, the Now Playing bar and the tabs. The reference for "one accent per screen" and for how flat shapes and air do all the separating.

- Order: Play button, at most one NoticeCard, "My Lists", "Songs". The whole body scrolls as one page; the title bar, Now Playing bar and tabs stay put.
- Body padding `space-4`; `space-6` above each section heading.
- No All Songs tile: every song is already listed under "Songs".
- Search filters only the songs. The list tiles stay where they are.
