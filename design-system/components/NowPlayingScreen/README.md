# NowPlayingScreen

Now Playing put together: Back, the big picture, title and artist, seek bar, controls, Up Next / Song Details, Volume. No tab bar or Now Playing bar here.

- Picture `size-art-hero`, `radius-lg`, centred. Title in `song-hero`.
- Only Play / Pause and the seek bar use `accent`; a toggle that is on (Shuffle: On) also takes it.
- The screen scrolls at large text sizes; the order of controls never changes.
